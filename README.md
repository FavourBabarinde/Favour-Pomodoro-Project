# Favour Pomodoro – FocusFlow V2

A modern desktop Pomodoro timer built with **Java Swing**, designed to help users manage their time, improve focus, and maintain a healthy balance between productivity and breaks.

FocusFlow V2 features a clean, dark-themed interface with a circular countdown timer, customizable work and break sessions, and simple controls for managing productivity.

### Features
- **Focus Sessions:** 25-minute productivity sessions.
- **Short Breaks:** 5-minute breaks between focus sessions.
- **Long Breaks:** 15-minute breaks after every four completed focus sessions.
- **Circular Countdown:** A real-time visual timer with a progress indicator.
- **Timer Controls:** Start, pause, resume, reset, and skip sessions.
- **Session Tracking:** Keeps track of completed focus sessions.
- **Modern UI:** Dark navy interface with coral accents, rounded buttons, and a minimalist design.
- **Standalone Windows Application:** Packaged as a Windows executable using Java's `jpackage` tool.

### Technologies Used
- Java
- Java Swing
- AWT / Graphics2D
- Java Timer
- JDK 26
- JAR and jpackage

### Project Purpose
This project is part of my journey in learning Java and desktop application development. It explores object-oriented programming, GUI development, event handling, timers, and application packaging.
